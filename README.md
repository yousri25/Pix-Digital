# Pix Revision

A single-page revision website for the Pix / C2i digital skills course.

## What's inside

- Pix reference: the 5 domains and 16 competences
- Basics: binary, units, bandwidth
- Networks: protocols, IP, DNS, client-server, internet access
- Security: phishing, malware, antivirus, firewall, file protection
- Interoperability and file formats: images, sound, video
- Data: saving, backups, versions, archives, compression
- C2i D1 slides: history, hardware, software, files, repair
- Glossary and a self-test with answers

## How to use

1. Download `pix-revision.html`.
2. Open it in any web browser.

No install and no internet needed, except for the Google font (a default font is used without it).

## Features

- Diagrams drawn in SVG
- Dark mode button
- Works on phone and desktop

Course files: Pix reference (January 2025), D5.1 / D1.2 / D5.3 / D1.4 course notes, Pix teaching support (domains 2, 4, 5), and the C2i D1 slides.
