2. Basics and units of information

Course D5.1, part 1 and 2

Informatique (information + automatique)All sciences and techniques related to information processing.
InternetThe worldwide computer network: many interconnected networks. It carries services (web, e-mail, messaging).
Do not confuse Internet (the network) with the web (one of its services).
(N)TICInformation and Communication Technologies: techniques for processing and transmitting information, born from computing, Internet and telecoms. TICE = the same, for Education.

Binary coding

A computer handles only 2 states. A bit (binary digit) is 0 or 1. An octet (byte) = 8 bits and gives 28 = 256 values: n bits give 2n values.

UnitValueTypical size
ko (kilo-octet)1 000 o (strictly 1 024 = 210)30-page text: ~200 ko
Mo1 000 ko5 Mpx JPG photo: ~2 Mo; 3 min MP3: ~3 Mo
Go1 000 MoDVD: 4.7 Go
To1 000 Go
Byte vs bit: 1 Byte = 8 bit. MB = Mo. Connection speeds are in bits per second, file sizes in octets.

Bandwidth (débit)

Bandwidth (loosely) = data rate, in kbps (kilobits per second). Real speed is always lower (network congestion).

Worked example. ADSL 1024k, photo of 2 Mo.
1024 kbit/s ÷ 8 = 128 ko/s. 2 Mo = 2048 ko. Time = 2048 ÷ 128 = 16 s.

Wireless

Wi-Fi (IEEE 802.11): wireless local network technology. Lets devices join a network and the Internet through an access point / box, within a building.
Bluetooth: short-range wireless technology. Used to link nearby devices: headset, mouse, phone, printer, game controller.
File pathList of folders to cross to reach a file. Starting from the root = absolute path (/home/me/doc.odt); otherwise relative path (../doc.odt).

3. Networks and Internet

Course D5.1, part 3

Computer networkEquipment linked to exchange information. LAN (local): one room or building. WAN (wide): large area; Internet is a WAN. A network allows sharing resources (files, printer, Internet access) and communication.

Client-server vs peer-to-peer

  • Server: computer with server software that answers client requests. Examples: web server (pages), FTP server (upload/download), mail server.
  • Needs a user directory with passwords (authentication) and specific rights per user or group.

Components of Internet

  • Media: cables (electrical signals), air (radio waves), optical fibre (light).
  • Linking networks: router (routes data), hub / switch (connect machines in a network), gateway (links two different networks, e.g. LAN to Internet).
  • Ends: home computers (temporary), host computers (always on, e.g. web server), peripherals (printer).

No element of Internet knows the whole network.

Protocols

Network protocolA set of rules that devices follow to communicate. TCP/IP handles transport: it cuts data into packets, routes them (possibly by different routes) and reassembles them at arrival. Application protocols serve one specific service.
ProtocolRole
TCP/IPTransport of data in packets; reassembled at arrival
HTTP(S)Web pages; the S means encrypted
FTPTransfer (upload/download) of files
SMTPSending mail (client → server, server → server)
POP3Retrieving mail: downloads it to your machine
IMAPReading mail kept on the server, synchronised across devices
DHCPAutomatically gives a device its network configuration (IP...)
IP addressIdentifies each machine on Internet: 4 integers 0-255 (4 × 8 bits) separated by dots, e.g. 74.125.39.106.
URL (Uniform Resource Locator)Address format that locates a resource: protocol + domain + path, e.g. https://www.google.fr/page.
DNS (Domain Name System)Translates a domain name into an IP address. Typing 74.125.39.106 gives the same site as www.google.fr.

Services, intranet, extranet

  • "internet" (lowercase) = any interconnected networks; Internet = the global one.
  • Web: hypertext pages. E-mail: electronic mail. Instant messaging: real-time chat.
  • Intranet: private network of an organisation using Internet technologies, closed to outsiders.
  • Extranet: an intranet partly opened, with authentication, to partners (clients, suppliers).

Getting online

ISP / FAICompany that gives you access to Internet (subscription). You need an ISP, a modem or box, and a medium.
AccessKey facts
RTC (phone line)Analog line, modem converts digital ↔ analog; 56 kbit/s; line busy
ADSLHigh speed, asymmetric; different frequencies from voice so phone stays free
CableTV network + modem; mainly big cities
Fibre opticVery high speed; costly to deploy
SatelliteRemote areas; needs a dish
3G+/mobileSIM card key or phone network
  • Box (Livebox, Freebox...) = ADSL modem + router: creates a LAN, Wi-Fi, file sharing, IP phone, TV.
  • Proxy (serveur mandataire): intermediary between your LAN and Internet. It forwards your request and returns the answer. Your IP is hidden: only the proxy's IP shows in the target's logs.
  • Public Wi-Fi: may need login or a prepaid card. You are not anonymous: your network card has a unique MAC address that can be recorded.

4. Security

Course D1.2 + Pix 4.1 to 4.3

Risks at a glance

Clumsiness / failure
Fix: regular backups.
Indiscretion
Hide files, limit access rights.
Ads / spam
Annoying, rarely dangerous.
Scams

Attacks

Nuisances

Spam (pourriel)Unsolicited bulk e-mail advertising (cheap way to reach many people). Mass sending uses harvested address lists. Legit company ads are collected with your consent and let you unsubscribe.
Pop-upWindow that suddenly appears, usually advertising. Two kinds: from a visited page (blockable in the browser) or from adware installed with free software (use an anti-spyware).

Scams

Hoax (canular)False message asking to be forwarded: virus alerts, chain solidarity, get-rich promises, petitions. Do not forward: it overloads networks and spreads false rumours. Check on a hoax-listing site (e.g. Hoaxbuster).
Phishing (hameçonnage)Fraud where the sender poses as a trusted third party (bank, administration) to steal personal data, via e-mail, fake websites or other means.

Attacks and malware

HackerComputing expert who explores systems. A cracker / pirate is a hacker acting illegally or unethically.
Malware (logiciel malveillant)Software designed to harm or spy. Spreads through the network or contaminated media (USB, CD).
TypeWhat it isWhat it can do
VirusProgram that attaches to another and duplicates itself; triggers on running the infected program or on an event (date, remote activation)Silly messages, disturb screen/mouse, destroy data
WormStandalone, self-propagating program (via mail, web page, network)Saturate resources, steal/destroy data, open a backdoor, slow the network
Trojan horseHarmless-looking program hiding a malicious function; infection follows opening a contaminated fileOpen a backdoor for remote control, steal passwords, collect/falsify data
SpywareCollects your information without consent, often installed with freeware/shareware (nobody reads the licence!)Infection → collection → transmission to a third party

Protection

AntivirusSoftware that detects, blocks and removes malware by comparing files with a database of viral signatures (the specific code a virus leaves). Three parts: resident protection (checks every new file), scanner (analyses a drive on demand), automatic update of signatures. On a hit it repairs, quarantines or deletes the file.
Firewall (pare-feu)Hardware or software filter that controls network traffic to protect sensitive data (passwords, identity) from intruders and software that could take control.

Protecting files

ConfidentialityInformation accessible only to authorised people.
IntegrityInformation stays exact and complete; not altered during processing, storage or transmission.
  • No one should see it → hide it. Read it → deny read access. Modify it → deny write / read-only.
  • Hidden file = attribute "Hidden" + folder options not showing hidden files. It is a weak hiding place: re-enabling "show hidden files" reveals it.
  • Network rights, per owner / group / everyone: read, write, execute.
  • Software protection: password on saving (OpenOffice), or encrypted archive (7-Zip, AES-256).

Good habits (Pix 4.1 / 4.2 / 4.3)

4.1Long unique passwords, password manager, multi-factor authentication, updates, backups, lock devices, careful with Wi-Fi and USB.
4.2Personal vs sensitive data, minimisation, privacy settings, geolocation, cookies and tracking, pseudonymisation. Ask: why, by whom, for how long, how visible?
4.3Ergonomics, breaks, notifications, cyberbullying, accessibility, environmental footprint, device lifespan, reuse, digital sobriety.
Reflexes: never open attachments of unknown origin (a friend's identity can be spoofed) · never answer spam (confirms your address is valid) · don't post your address publicly · don't install doubtful software and read the licence · keep antivirus updated.

5. Interoperability and file formats

Course D5.3

NormReference published by a standardisation body (ISO, IEEE, AFNOR) after consensus. Ex: Wi-Fi = IEEE 802.11; OpenDocument = ISO 26300.
StandardReference published by another entity and widely used in practice. Open if freely published, closed otherwise.
Compatibility
Two systems made to work together.
Interoperability
A system whose interfaces are fully known can work with other systems (thanks to an open norm/standard).
Open worldProprietary world
Open standards. OpenOffice formats odt, ods, odp are open: any publisher can support them.Format not (fully) published for commercial reasons, locking users in. Microsoft .doc is proprietary (loss of info elsewhere); .docx (2007) is a bit more interoperable. Many instant messengers are incompatible (proprietary protocols).

Images

  • Vector: scalable without loss; technical drawings, maps. Formats: svg (open), odg (open), wmf/emf (Microsoft).
  • Raster: spatial resolution = number of pixels; dynamic = number of colours. Enlarging degrades quality.
FormatCompressed?Use
BMPNoSimple, huge files, rare on the web
JPEG / JPGYes, with lossPhotos, 16 M colours; lose sharpness on edges
GIFYesDrawings, 256 colours, transparency, animation, interlacing
PNGYes, losslessNot limited to 256 colours; worse than JPG for photos

Colour depth: 8 bits → 28 = 256 colours (colormap). 24 bits (3 octets) → 224 = 16 million (True Color).

Worked example (BMP size). Photo 900 × 600 px = 540 000 pixels. 24-bit BMP: 540 000 × 3 = 1 620 000 o ≈ 1.54 Mo. (The course text writes 3600 by typo.) Measured sizes: JPG 100% 379 Ko · JPG 50% 41 Ko · GIF 274 Ko · PNG 231 Ko.
A 6 Mpx photo (3072 × 2048) would be 18.9 Mo as BMP versus 2.25 Mo as JPG.

Sound

Sound is digitised by sampling air pressure at regular intervals. Sampling rate: CD 44.1 kHz, radio 22.05 kHz, phone 8 kHz. Resolution: bits per sample (8 bits → 256 values, 16 bits → 65 536). This is PCM.

5 min CD stereo 16-bit: 44 100 × 2 o × 2 channels = 176 400 o/s → × 300 s = 52.9 Mo (≈ 50 Mo).
  • Uncompressed: cda (audio CD), wav (Microsoft), aif (Apple).
  • Compressed: mp3 (loss, licence for commercial use), wma (proprietary, copy protection), ogg (open, free, streaming), aac / m4a (Apple).

Video

Video = images (25 per second) + sound.

1 min, 720 × 576, true colour: 720 × 576 × 3 × 25 × 60 = 1 866 240 000 o ≈ 1.7 Go. Sound only 10.6 Mo, so images dominate → compression is required (3 min wouldn't fit a 4.7 Go DVD).
CodecCompression/decompression algorithm for audio/video. Bit rate: bits needed per second. Audio CD uncompressed = 44 100 × 16 × 2 = 1 411 200 bit/s (≈ 1 378 kibit/s). At 128 kbit/s the file is ~11× smaller. A 3-min track: 30 Mo → 2.8 Mo.
  • M-JPEG: JPEG on each image, good for editing, bad for streaming. MPEG: stores only differences between images. MPEG-1 (CD), MPEG-2 (DVD, digital TV), MPEG-4 (web, mobile, streaming). DivX: proprietary codec based on MPEG-4, film on ~700 Mo.
  • Containers: avi (Microsoft), mpg/mp2/mp4, mov (QuickTime/Apple), flv (Flash).

Work happens in RAM, which is volatile: it empties when power is off. Save to a storage device.

  • Keep the same order of info (subject, date, author) and put the date reversed.

Special folders: Desktop (items on the screen background), Recycle bin (deleted files), Documents / Images / Music.

Archive and compression

ArchiveA single file holding a tree of folders and files. Useful for e-mail attachments, one-click downloads, structured storage. Often compressed, but not necessarily.
LossyLossless
Smaller by accepting small quality loss: jpg, mp3.Smaller with no loss, using software (7-Zip) that replaces repeated patterns by shorter codes. Big gain on txt/bmp, tiny on already compressed jpg.

Compress → archive → decompress gives back the identical file; saves time (transfer) and space. A recipient needs decompression software, or send a self-extracting archive.

History and hardware

YearMilestone
1971Intel 4004, first microprocessor (4-bit, 2 300 transistors)
1976-77Apple 1, then Apple II, Commodore PET: first machines for the public
1978Intel 8086 (16-bit)
1984Macintosh: graphical interface + mouse. PC compatibles take over (IBM, Compaq, Dell, HP...)
  • Moore's law (empirical): processor power doubles about every 18 months.
  • Boot: ROM runs the BIOS (checks hardware) → loads the operating system (Windows, Linux, Mac OS).
  • Key specs: CPU power (speed), RAM (volatile, runs current programs), storage capacity, OS, ports.
  • Ports: USB (hot-plug), Ethernet RJ45 (LAN), VGA (analog screen), HDMI (digital HD screen).
  • A new device may need a driver (lets the OS manage it); Plug and Play downloads it automatically.

Work environment

= a workstation + its peripherals, applications (local or on remote servers), storage spaces (local or remote). Remote services = cloud computing: accessible from any connected device, maintenance and backup done by the provider.

  • Accounts: a single user is the administrator; multi-user machines authenticate, then open a session by profile (admin, user, guest). Only an admin can install software.
  • File manager = Explorer (Windows), file browser (Linux), Finder (Mac).
  • ENT: single access point integrating all services of one's activity. Also: collaborative platform, e-learning platform, social network. Before publishing online, ask who can access it.

IP addresses

IPv4 = 32 bits (≈ 4 billion addresses, shortage). IPv6 = 128 bits (16 octets, ≈ 1038 addresses). On a LAN/box you share one external IP and have a local IP. Wi-Fi networks: secured (WEP/WPA key) or open (captive portal asking login or payment).

Software

  • Application (user-facing) vs system software (between apps and hardware). Install from CD or downloaded executable, needs admin rights and sometimes a licence key.
  • Update to fix bugs and security flaws. Uninstall with the proper procedure, never by deleting the folder. A desktop icon is only a shortcut: deleting it doesn't uninstall.
  • Examples: office suite (OpenOffice free / Microsoft Office proprietary), browser (Firefox, Chrome), mail client (Thunderbird; set incoming server, outgoing server, address), image editor (GIMP), PDF reader, antivirus, compression (7-Zip).

Files and storage

  • Storage (RAM can't keep data): hard drive, removable (USB key, memory card, external disk, CD/DVD/BD), online (ENT, remote file server via FTP). Optical: -ROM read only, -R write once, -RW/-RE rewritable.
  • Tree: files in folders and sub-folders. Windows: C:\Alex\C2i\D1\Fiche.odt (absolute path from root C:); relative: ..\C2i\D1 where .. = parent folder. Linux: /home/Alex/C2i/D1/Fiche.odt.
  • Extension = file-name suffix. Format = how data is coded: not the same thing! Renaming .png to .jpg does NOT convert it; use "Save as" with another type.
  • Tags: several per file, more flexible than folders (one folder only). Deleting a shortcut does not delete the file.
  • Text files (readable in any editor): txt, csv, html, odf (XML). Binary files: doc, jpg, executables.
  • Obsolescence: formats and media age, so convert old files and re-copy backups. Floppy 360 ko (1981) → 1.44 Mo → CD 700 Mo → USB key 2-32 Go.

Backup vs save

Open = load into memory. Save (enregistrer) = write to storage. Backup (sauvegarder) = duplicate as a safety copy.
  • Backup on an external medium (another folder of the same disk is useless if the disk fails). Emailing yourself the file is a quick backup.
  • Back up all data weekly/monthly, modified files daily. No need to back up applications.

Document formats

TypeOpen / interoperableProprietary
Texttxt, rtf, odt, docx (OOXML)doc
Spreadsheetcsv (text, no formulas), ods, xlsxxls
Presentationodp, pptx, html (online)ppt
Fixed layoutPDF: keeps formatting, not meant to be edited

Image notes: JPEG is advised for photos; GIF/PNG for drawings. GIF uses an indexed 256-colour palette; PNG's palette isn't limited. Audio/video: wma (proprietary), mp3 (open, lossy), MPEG-4 (video).

Traces and privacy

  • Browsing traces: history (URLs), bookmarks, cache (files kept to load pages faster the second time), downloads.
  • Cookie: small text file stored by the browser. Kinds: identification (stay logged in), preference (language), advertising (targeted ads).
  • Saved passwords can often be displayed in clear. Use private browsing, clear history/cookies, refuse password saving.
  • Remote workspace: private space, strong password, log out.

Malware details

  • Virus kinds: boot virus (loaded at startup), application virus (infects an executable), macro virus (infects office documents).
  • Worm doesn't need a host program. Trojan does not reproduce. Adware shows ads and sends data to adapt them; often bundled with free software and treated like spyware.
  • Dangerous executable extensions: exe, sys, com, jar. Download from official sites. You are the best antivirus!

Repair

SymptomReaction
Won't bootOlder system version or safe mode (press the key shown at BIOS stage, e.g. F2)
FreezesForce-quit the app from the keyboard; else hold the power button for a few seconds (don't unplug)
Sudden stopFollow the on-screen advice, restart; if repeated uninstall the last app / restore an earlier state; last resort: reinstall the system (create restore DVDs early)

Causes: compromised install/update, a bug, malware or intruder.

Units (precise)

Real conversion uses 1024 = 210: 1 Kio = 1 024 o · 1 Mio = 1 048 576 o · 1 Gio = 1 073 741 824 o. Everyday "ko/Mo" are used loosely.

9. Self-test

Answer in your head, then open.

How many values on 8 bits? On 10 bits?

28 = 256; 210 = 1 024.

A 15 Mo file on a 2048 kbit/s line: download time?

2048 ÷ 8 = 256 ko/s. 15 000 ko ÷ 256 ≈ 58.6 s at best (using 1 Mo = 1000 ko).

Internet vs the web?

Internet is the network; the web is one service on it.

POP3 vs IMAP?

POP3 downloads mail to your machine; IMAP keeps it on the server, synchronised.

What does a proxy hide?

Your IP: the target only sees the proxy's.

Virus, worm, trojan: key difference?

Virus needs a host program; worm spreads by itself; trojan pretends to be useful.

Which image format for a photo? A logo that must scale?

JPEG for photos; SVG (vector) for a scalable logo.

Best file name for a 5 Nov 2009 version?

EXPOSE_20091105.odt (reversed date sorts chronologically).

Norm vs standard; compatible vs interoperable?

Norm: from a standardisation body. Standard: widely used reference from any entity. Compatible: built to work together. Interoperable: works with others thanks to known/open interfaces.

Confidentiality vs integrity?

Confidentiality: only authorised people access it. Integrity: it is exact, complete and unaltered.

Spot the phishing clues.

Odd sender, artificial urgency, misleading link, unexpected attachment, unusual data request.

Steps to diagnose "no Internet"?

Wi-Fi/cables, local connection, test another device, restart, network settings, then support.
